# Contributing

- Branch from `main`, open a pull request, and fill in the template. Every PR gets its own preview (API, web app, phone update) once deploys are enabled.
- Run `pnpm check` before pushing. CI runs the same checks plus a browser test of two people chatting.
- Rules for space data, Durable Objects, migrations and privacy are in [CLAUDE.md](CLAUDE.md); they apply to people too.
- Use made-up people and data in tests and screenshots.
