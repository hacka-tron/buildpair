Buildpair on the desktop

The web version, drawn at laptop size (1120 px wide) in the same Margin Notes style as the phone screens. Many builders will use Buildpair at their desks, so the goal is parity with the phone app plus the things a big screen and a keyboard do better.

Three columns: the sidebar (four places and your spaces), the page, and a quiet margin on the right. Each area has one job: Today is for planning, a space is for its chat, Supporting and Discover are for people.

14. Window sizes: from a wide monitor down to phone width

The layout gives up panes in a fixed order as the window narrows: first the margin, then the sidebar's labels, then the sidebar itself.

What this adds up to

Every phone screen has a desktop version. Each area keeps a clear focus: Today for planning, spaces for their chat, Supporting and Discover for people. The desktop adds item details, the command palette, the Upcoming week view and the one-screen weekly review.

Still to draw: dark mode versions of these screens, onboarding at desktop size, empty states (no spaces, no supporters, empty Discover), the focus timer, and the Pro upgrade screen. The browser frames and phone frames are drawn in the light theme only.
